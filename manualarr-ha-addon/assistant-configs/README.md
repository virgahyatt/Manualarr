# Assistant Configuration Templates

These templates help you integrate Manualarr with Home Assistant conversation agents.

## Available Templates

- [Extended OpenAI Conversation](./extended-openai-conversation.yaml) - **Recommended** for OpenAI, Azure, and Ollama.
- [Google Generative AI](./google-generative-ai.yaml) - For Google Gemini models.
- [Ollama / Local LLM](./ollama-local-llm.yaml) - Specific notes for local models.
- [Generic REST Tool](./generic-rest-tool.md) - For other custom integrations.
